# Support

<p><a href="./SUPPORT.md">Türkçe</a> · <strong>English</strong></p>

Use [GitHub Discussions Q&A](https://github.com/Makaytron/Etsy-Automation-Tools/discussions/categories/q-a) for installation and usage questions, and the [GitHub issue forms](https://github.com/Makaytron/Etsy-Automation-Tools/issues/new/choose) for reproducible bugs.

Include:

- Affected script and version
- Installation source: canonical raw `main`, another distribution platform, or a local copy
- Browser and Tampermonkey version
- Etsy page or workflow, without shop/customer/order identifiers
- For analyzer integration issues, which scripts are installed, only the first eight characters of the request ID, and the visible handshake state without keyword/listing content
- Expected and actual behavior
- Reproduction steps
- Redacted screenshot
- Redacted console error, when relevant

Never include API keys, cookies, access tokens, nonces, full request IDs, customer messages, order information, shop/listing identifiers, title/tag content, Marketplace Insights metrics, advertising metrics, or complete authenticated Etsy HTML.

Report security-sensitive problems privately through [SECURITY.en.md](./SECURITY.en.md).
