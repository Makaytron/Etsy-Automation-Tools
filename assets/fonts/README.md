# Fonts

Inter (rsms/inter) and JetBrains Mono, both under the SIL Open Font License 1.1
(https://openfontlicense.org). Downloaded as the woff2 subsets Google Fonts
serves (Inter 400–700 variable; JetBrains Mono 500–700 variable).
`unicode-ranges.tsv` lists each file's family, subset and unicode-range.

The unified build embeds them in the userscript, so Etsy pages show the
design canvas's type without loading anything from the network.
