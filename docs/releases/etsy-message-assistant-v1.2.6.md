# Makaytron Etsy Message Assistant v1.2.6

This standalone release promotes the post-`1.2.5` Message Assistant work already reviewed on `main` into a versioned, installable package.

## Highlights

- Adds role-labelled translations below the latest customer and seller bubbles without replacing the source text.
- Adds shared quick AI drafting, translation, editing, and **Send to customer** controls beside Etsy's composer.
- Revalidates conversation, text, composer, ownership, and outgoing-bubble evidence around the single native Etsy send action; an uncertain result is never retried automatically.
- Adds 4–5 star review analysis with separate private thank-you and public response drafts while rejecting incentives, rating-change requests, public order details, unsafe links, and stale review context.
- Keeps every private message and public review response under explicit user control; public responses are never auto-published.

## Package assets

- `Makaytron-Etsy-Message-Assistant.user.js`
- `SHA256SUMS.txt`

The userscript asset must be byte-identical to the reviewed source at the signed `etsy-message-assistant-v1.2.6` tag. The suite release remains GitHub `Latest`.
