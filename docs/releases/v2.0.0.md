# Etsy Automation Tools bundle v2.0.0

This suite release introduces **Makaytron Etsy Automation Tools**, a single userscript that contains all five Makaytron tools, and brings the five standalone scripts up to date with a move notice and an encrypted transfer into it.

## Highlights

- Makaytron Etsy Automation Tools `2.1.0` runs each standalone tool's own engine behind one edge button, drawer and full-window workspace, with shared settings, backup and restore, and local data deletion. Its interface follows the Makaytron design canvas in light and dark, with Message Assistant conversations, quick replies and autopilot, Listing Analyzer overview, listings, AI suggestions, queue and thresholds, notifications, keyboard shortcuts and an update check.
- First-run setup opens in the browser's language. Only English is built in in full; 42 more languages, Turkish included, are downloaded once from this repository when chosen, validated and kept.
- Report a problem shows every field of the report first and then opens a prefilled public GitHub issue. The script sends nothing itself, and the unified build has no telemetry.
- The standalone scripts show a notice about the unified script and can transfer their settings and data to it, encrypted on the page with a matching check code on both sides. API keys never move.
- Live Etsy fixes: Sale Manager reads promotions from Etsy's all-time list, Ads Keyword Manager opens Etsy's collapsed targeted-keywords section, and Listing Analyzer reads both metric scopes from Etsy's combined card block.
- Makaytron Etsy Automation Tools is about 3.5 million characters (it embeds its fonts), above Greasy Fork's 2,000,000-character limit, so it is distributed from GitHub only. The five standalone scripts stay on Greasy Fork.
