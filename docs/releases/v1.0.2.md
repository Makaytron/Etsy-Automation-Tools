# Etsy Automation Tools v1.0.2

This is the first GitHub Release sent through the Greasy Fork release webhook for all five standalone userscripts in `Makaytron/Etsy-Automation-Tools`.

## Highlights

- Verified every live homepage, support, Raw update/download, logo, privacy, issue, and GitHub API URL against the canonical repository.
- Preserved legacy `@namespace` values solely as installed userscript identities; no network request uses the retired repository.
- Kept the existing `@antifeature tracking` disclosure for the documented privacy-preserving telemetry.
- Configured five Greasy Fork listings for automatic synchronization from their exact nested public Raw `main` paths.
- Added a GitHub webhook subscribed only to `release` so a published release requests an immediate Greasy Fork refresh.
- Gave Greasy Fork no GitHub OAuth grant, token, deploy key, GitHub App, or repository write permission.
- Added local version/syntax/secret checks and post-push byte-equivalent Raw source validation.
- Corrected the Listing Analyzer update-check documentation to match the implemented 24-hour interval.
- No Etsy reading, navigation, write, send, storage, or automation behavior changed in this release.
