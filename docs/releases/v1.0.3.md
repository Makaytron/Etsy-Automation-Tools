# Etsy Automation Tools bundle v1.0.3

This bundle hardens the two Research companion update paths, ships Listing Analyzer v1.0.4 with multi-page collection and Health Engine correctness fixes, and leaves the other four standalone packages at v1.0.3.

## Highlights

- Keyword & Market Analyzer now resolves GitHub `main` through the public commit API, fetches the exact immutable-commit userscript, and opens that same SHA-pinned file only after the user selects **Update**.
- Keyword & Market Analyzer excludes its own inline result panels from subsequent Marketplace Insights reads and deduplicates those panels, preventing pagination data bleed.
- Listing Analyzer and Keyword & Market Analyzer require exact product name, legacy installed-script namespace, strict SemVer, canonical `@updateURL`, and canonical `@downloadURL` metadata with no duplicate directives.
- Exact HTTPS target checks reject host, port, path, query, fragment, and credential drift.
- Active Keyword research, Listing collection, or Listing action-queue work blocks the installation handoff.
- Automated tests cover new-version warnings, visible update actions, current-version silence, immutable install URLs, GitHub API failures, redirect drift, wrong products, missing or duplicate metadata, tampered install state, and active-work fences.
- Listing Analyzer now accepts a page only after three identical complete reads, validates pagination/card counts and the seller-nav public shop identity, scopes metrics to canonical card statistic rows, rejects overlapping pages, and invalidates older collection manifests.
- Listing Analyzer resolves the current listings page from Etsy's validated route parameter and navigates through the pagination select `input`/`change` contract before falling back to icon buttons, preventing page 2+ identity and transition failures.
- Listing Analyzer treats renewal/expiry copy as renewal metadata rather than activity status, binds Etsy's verified listing-state filter to the collection scope, and excludes non-active records from active cohorts and deactivation safeguards.
- Health Engine keeps missing same-day metrics unknown, requires a real 60-day anchor for dormant status, benchmarks only fresh current-collection peers, uses rolling 30-day performance filters/calibration, and keeps seasonal deactivation fail-closed.
- Ads Keyword Manager reads nested Etsy keyword and metric text while excluding responsive headers and hidden accessibility text, waits for semantic row hydration, keeps narrow-panel actions inside the card, and uses the Makaytron logo launcher when collapsed.
- Saved Etsy fixtures for pages 1, 2, 3, and 17 validated 40, 40, 40, and 13 listings respectively: 133 unique IDs, all five metrics complete, and no cross-page overlap. Pages 4–16 were not present in the supplied archive and are not claimed as live-fixture coverage.
- Offline regression suites pass 24 Listing Analyzer checks, 11 updater checks, and 4 Ads Keyword Manager checks; local distribution validation covers all five userscripts.
