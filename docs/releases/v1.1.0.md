# Etsy Automation Tools bundle v1.1.0

This suite release brings the canonical five-script bundle up to date with the current standalone sources on `main`. It includes the substantially expanded Message Assistant and Listing Analyzer while preserving the existing Sale Manager, Ads Keyword Manager, and Keyword & Market Analyzer versions.

## Highlights

- Message Assistant `1.2.6` adds role-aware conversation translation, verified quick-reply sending, and review-response drafting with strict stale-context and no-auto-publish safeguards.
- Listing Analyzer `1.2.2` adds active-epoch analysis, context-aware cohorts, exact experiment intervals, quality-aware charts, validated AI JSON comparison, and fail-closed user-approved action queues.
- The suite remains five independently installable userscripts with GitHub as the canonical source, Greasy Fork as the primary userscript host, and SourceForge as the release mirror.
