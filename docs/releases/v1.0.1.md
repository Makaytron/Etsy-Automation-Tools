# Etsy Automation Tools v1.0.1

This distribution patch publishes all five standalone userscripts from the canonical `Makaytron/Etsy-Automation-Tools` repository and establishes release-driven Greasy Fork updates.

## Highlights

- Verified every live homepage, support, Raw update/download, logo, privacy, issue, and GitHub API URL against the new canonical repository.
- Preserved legacy `@namespace` values solely to keep installed userscript identities stable; no network request uses the retired repository.
- Added explicit `@antifeature tracking` metadata for the documented privacy-preserving telemetry.
- Published five Greasy Fork listings backed by their exact nested public Raw paths.
- Added one release-only GitHub webhook. Greasy Fork receives public release notifications but no GitHub credential or write access.
- Added a credential-free local validation command and repository secret-deny patterns.
- No Etsy reading, navigation, write, send, storage, or automation behavior changed in this patch.
