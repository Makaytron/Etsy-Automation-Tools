# Etsy Automation Tools bundle v1.0.4

This distribution-only suite release restores one clear, current download for all five standalone userscripts. It does not change script logic or raise any component version.

## Distribution fixes

- Publishes a current five-script bundle instead of presenting one standalone package as the project-wide latest download.
- Accompanies dedicated standalone releases for Ads Keyword Manager, Listing Analyzer, and Keyword & Market Analyzer so every current package is directly discoverable in the GitHub and SourceForge release trees.
- Keeps the suite release as GitHub `Latest` and requires SourceForge's public default download to resolve to the suite ZIP rather than a generated source archive.
- Extends hosted validation to fail when either latest/default selection drifts again.

## Package versions

- Makaytron Etsy Sale Manager: `1.0.12`
- Makaytron Etsy Message Assistant: `1.0.4`
- Makaytron Etsy Ads Keyword Manager: `1.0.3`
- Makaytron Etsy Listing Analyzer: `1.0.5`
- Makaytron Etsy Keyword & Market Analyzer: `1.0.3`
